# SimpleBOM releases

SimpleBOM is a Windows desktop app for building and managing bills of materials efficiently. It works offline on your own computer.

This repository holds the downloads and nothing else. The source code is private.

## Download

1. Open the [latest release](https://github.com/alextmad/simplebom-releases/releases/latest).
2. Under **Assets**, download the `SimpleBOM_..._x64-setup.exe` installer.
3. Run it. It installs for your Windows account only and does not ask for administrator rights.

SimpleBOM is early access. The app can check this repository for newer versions.

## You need a personal key

Each early tester gets a personal key from the developer. SimpleBOM asks for it on first launch. If you do not have one, ask the person who invited you.

## Something is wrong

Issues are switched off here. Inside SimpleBOM, choose **Help > Report a problem**. That sends the report straight to the developer.

Security problems go through the private route in [SECURITY.md](SECURITY.md), never through a public report.
